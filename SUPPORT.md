# Support

## Getting Help

FIBEMATE is a solo-developed post-quantum cryptography engineering project.
We're happy to help — just pick the right channel for your question.

### 📖 Documentation First

Before reaching out, check:

- **[README.md](README.md)** — project overview, quick start, security model
- **[BUILD.md](BUILD.md)** — build from source, dependency installation
- **[docs/pqc-readiness.html](https://fibemate.net/docs/pqc-readiness.html)** — PQC deployment status, TVLA results, FPGA timing
- **[docs/API.md](docs/API.md)** — client-side crypto API reference
- **[docs/FAQ.md](docs/FAQ.md)** — common questions

### 💬 Community Support

- **GitHub Discussions** — Best for general questions, architecture decisions, roadmap feedback
  → [FIBEMATE Discussions](https://github.com/Lennonhaha/fibemate/discussions)

### 🐛 Bug Reports & Feature Requests

- **GitHub Issues** — For reproducible bugs, concrete feature requests
  → [Open an Issue](https://github.com/Lennonhaha/fibemate/issues/new/choose)
- Use the Bug Report template for defects, Feature Request template for ideas

### 🔒 Security Vulnerabilities

- **DO NOT** file public issues for security bugs
- See **[SECURITY.md](SECURITY.md)** for the private reporting process
- Email: `fibemate@fibemate.net` | Expected response: 72 hours

### 📧 Direct Contact

- **Email**: `fibemate@fibemate.net`
- For collaboration inquiries, audit requests, or anything that doesn't fit the channels above

### ⚠️ Scope

This project is under active solo development. Response times may vary, but we read everything.
For production-critical deployments, please wait for the completion of an independent third-party security audit (planned Q4 2026).
