# PQC 迁移路径决策树 — 可视化设计文档

**类型**：交互式决策树
**状态**：设计阶段（冻结期内不实现）
**优先级**：#4

---

## 1. 目标

把"我该不该迁移 PQC、先迁移什么"变成一个可点击的决策树。每个节点代表一个判断条件，每条路径通向一个具体建议。

---

## 2. 数据来源

| 数据项 | 来源 |
|--------|------|
| 迁移优先级指数 (WPI) | `www/docs/migration-priority.html`（12 资产） |
| PQC 就绪度评估 | `www/docs/pqc-readiness.html` |
| 仪表盘数据 | `www/docs/pqc-dashboard-data.json`（16.2KB, 12 算法） |
| 已知问题列表 | `www/docs/known-issues.md` |

---

## 3. 决策树结构

```
                        你的组织类型？
              ┌─────────────┼─────────────┐
           政府/       金融/支付/     个人/中小
         关键基建        电商           企业
              │              │              │
         SM2 为主      混合签名      WPI 评估
              │       (SM2+RSA/ECDSA)   (<50→推迟
              │              │           ≥50→推进)
        ┌─────────┐   ┌─────────┐
      已有 SM2?  否  证书≤3年? 否
       │    │       │    │
      是   先上     是   慢迁
       │   SM2       │
    ML-KEM   │    ML-KEM
    混合KEX  │    混合KEX
      │      │       │
    Path C-2  Path A  仅 KEX
    (IANA    (TLS 1.3  优先
     #4590)  #4588)
```

### 3.1 节点类型

| 节点 | 类型 | 交互 |
|------|------|------|
| 问题节点 | 二/三择，用户点击选项 | 点击后高亮选中，展开子节点 |
| 结论节点 | 建议 + 理由 + 预计迁移周期 | 颜色分级（绿/黄/红 = 急/缓/不关你事） |
| 数据节点 | 引用 WPI 数据 | 悬停显示具体数值 |

### 3.2 颜色编码

| 颜色 | 含义 |
|------|------|
| 🟢 绿色 | 立即迁移，PQC 替代品已成熟 |
| 🟡 黄色 | 计划迁移，监控标准化进展 |
| 🔴 红色 | 暂不迁移，等待标准/工具成熟 |

---

## 4. 交互设计

| 交互 | 行为 |
|------|------|
| 点击问题选项 | 展开对应路径，其他路径收起 |
| 悬停结论节点 | 弹出卡片：预计时间线 + 推荐算法 + 注意事项 |
| 悬停数据节点 | 显示具体 WPI 数值和计算依据 |
| "开始"按钮 | 回到根节点，清空路径 |
| 面包屑导航 | 顶部显示当前路径："政府 → 已有 SM2 → ML-KEM 混合 KEX" |

---

## 5. 技术栈

- D3.js 力导向图 或 纯 Canvas 2D 树布局

- 倾向纯 Canvas 实现，零依赖
