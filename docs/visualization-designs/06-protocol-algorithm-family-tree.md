# 协议层次与算法族谱联动图 — 可视化设计文档

**类型**：层级树 × 拓扑图联动
**状态**：设计阶段（冻结期内不实现）
**优先级**：#6

---

## 1. 目标

把 FIBEMATE 的全部密码学资产按「协议层 → 算法族 → 具体实现」组织成可展开的族谱树。左侧选层 → 右侧展示该层内部数据流拓扑。让观众快速理解"FIBEMATE 里有什么"。

## 4. 左侧：族谱树

- 树形展开，四层可全部折叠/展开
- 叶子节点：具体实现文件（点击跳转 GitHub 源码）
- 中间节点：协议名/算法族
- 节点旁徽章：KAT ✅ / TVLA ✅ / TSR 218

## 5. 右侧：数据流拓扑

选中左侧节点后，右侧展示其内部数据流：

```
例：选中 Tunnel C-2 → 右侧
┌──────────────────────────────────────────┐
│  Alice                                Bob │
│                                            │
│  sm2_keygen ────────── pk_sm2 ────────►    │
│  mlkem_keygen ──────── pk_mlkem ──────►   │
│                                            │
│               ◄─────── ct_mlkem ────────   │
│               ◄─────── encrypted_conf      │
│                                            │
│  ss = HKDF(sm2_ss ‖ mlkem_ss)              │
│  verify 解密 conf 确认                      │
└──────────────────────────────────────────┘
```

## 6. 节点元数据卡片

悬停每个节点弹出：

| 字段 | 内容 |
|------|------|
| 算法名称 | 标准名 + IANA 号 |
| 安全等级 | NIST-I/III/V 或 实验性 |
| 证据链 | KAT 向量数 / TVLA PASS / TSR 数量 |
| 性能 | 签名 o/s、验证 o/s |
| 状态 | 活跃 / Shelved / 规划中 |
| 实现路径 | 源文件链接 |

## 7. 交互设计

| 交互 | 行为 |
|------|------|
| 左侧点击树节点 | 高亮节点，右侧刷新拓扑 |
| 左侧折叠/展开 | +/- 按钮 |
| 右侧点击数据流节点 | 弹出元数据卡片 |
| 搜索框 | 搜索算法名，树自动展开到匹配节点 |
| 全屏按钮 | 展开/收起左侧面板 |
