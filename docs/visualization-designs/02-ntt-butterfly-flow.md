# NTT 蝶形运算动态流 — 可视化设计文档

**类型**：2D 逐步展开动画
**状态**：设计阶段（冻结期内不实现）
**优先级**：#2

---

## 1. 目标

将 CT (Cooley-Tukey) 蝶形 NTT 的逐层分解过程用动画展开，让观众理解"多项式乘法为什么能这么快"。

**核心叙事**：O(n²) 暴力乘 → O(n log n) NTT → 蝶形网络 8 层展开。

## 3. NTT 蝶形网络结构

```
输入层 (自然序)                   输出层 (bit-reversed)
 x₀     ─┬─                      ── X₀
 x₁     ─┼─┬─                    ── X₁₂₈
 x₂     ─┼─┼─┬─                  ── X₆₄
 ...      │ │ │
 x₂₅₅   ─┴─┴─┴─                 ── X₂₅₅

8 层 × 128 个蝶形/层 = 1024 次 fqmul
```

每层：128 对系数做"加/减×zeta"操作

## 4. 视觉设计

### 4.1 主视图：蝶形网络展开

| 元素 | 设计 |
|------|------|
| 256 个输入节点 | 排列在左侧，颜色映射到系数值（蓝=负 → 白=0 → 红=正） |
| 8 层蝶形节点 | 每层 128 对，用弧形连线连接 |
| zeta 标注 | 每个蝶形连线中点标注 zetas[k] 值（小字号） |
| 输出节点 | 排列在右侧，颜色同输入 |

### 4.2 单步模式

| 控制 | 行为 |
|------|------|
| 前进一层 | 高亮当前层的全部连线和节点 |
| 前进一个蝶形 | 高亮单个蝶形（两个输入→两个输出），显示 a,b → a+b*zeta, a-b*zeta 的数学细节 |
| 自动播放 | 0..7 层逐层展开，每层 ~500ms |
| 速度 | 0.5×/1×/2×/4× |

### 4.3 侧面板：数学信息

| 显示项 | 内容 |
|--------|------|
| 当前层 | "第 3/8 层，zeta = zetas[2..3]" |
| 模约简 | 显示 montgomery_reduce / barrett_reduce 调用次数 |
| 性能 | "本层: 128 次 fqmul ≈ 2.3µs @ 3GHz" |
