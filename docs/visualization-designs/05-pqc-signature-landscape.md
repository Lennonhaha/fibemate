# 后量子签名方案对比图 — 可视化设计文档

**类型**：多维度散点图 + 折线图
**状态**：设计阶段（冻结期内不实现）
**优先级**：#5

---

## 1. 目标

在一个页面上对比所有主流 PQC 签名方案的四个核心维度：签名尺寸、公钥尺寸、签名速度、验证速度。支持 2D/3D 切换和方案筛选。

---

## 2. 数据来源

| 数据项 | 来源 |
|--------|------|
| ML-DSA-44/65/87 | `packages/fml-dsa/`（noble fallback 基准） |
| FALCON-512/1024 | 文献数据（FIPS 206 草案） |
| SLH-DSA-128s/192f | `packages/fips205/` |
| ECDSA P-256 | `sm2-bigint-ec.js`（实测） |
| VWZ k=8/16 | `vwz-performance.html`（实测：签名 24527/4765 ops/s） |

---

## 3. 视觉设计

### 3.1 默认视图：2D 散点图

| 轴 | 含义 | 方向 |
|----|------|------|
| X | 签名尺寸 (bytes) | 越小越好 ← |
| Y | 签名速度 (ops/s) | 越快越好 ↑ |
| 气泡大小 | 公钥尺寸 | 越小越好 |
| 气泡颜色 | 安全等级/信任度 | 绿=NIST 标准, 黄=FIPS 草案, 红=实验性 |

### 3.2 可切换维度

| 切换按钮 | X 轴 → | Y 轴 → |
|----------|--------|--------|
| 尺寸优先 | 签名尺寸 | 公钥尺寸 |
| 速度优先 | 签名速度 | 验证速度 |
| 综合 | 签名尺寸×公钥尺寸 | 签名速度×验证速度（乘积） |

### 3.3 折线图模式

| 对比维度 | 折线 |
|----------|------|
| 安全等级对尺寸 | ML-DSA-44 → 65 → 87 签名尺寸变化 |
| 安全等级对速度 | ML-DSA-44 → 65 → 87 签名速度变化 |
| 同等级跨方案 | ML-DSA-65 vs FALCON-512 vs VWZ k=8 |

### 3.4 雷达图模式

每个方案一个五边形：
- 角 1: 签名尺寸（归一化，越小越好）
- 角 2: 公钥尺寸
- 角 3: 签名速度
- 角 4: 验证速度
- 角 5: 安全信任等级
