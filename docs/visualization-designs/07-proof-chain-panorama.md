---

## 0. 命名与定位

**名称**：证明链全景（Proof Chain Panorama）

**定位**：将 FIBEMATE 的"算法 → 验证 → 存证"三层关系，用一张可交互的 3D 拓扑图呈现。核心叙事是**可验证性**——每个算法节点都能追溯到它的验证证据（KAT / TLA+ / TVLA / TSR）。

**边界声明（诚实版）**：
- 本页只展示**已完成和已规划的真实工作**，不虚构任何不存在的验证能力。
- 不引入"公理切换""数学宇宙""AI 自动证明"等概念——这些不在项目能力范围内。
- 密码学安全假设（LWE / 格困难性）是计算复杂度假设，**不可视化为可切换的公理选项**。

---

## 1. 目标

1. 一张图讲清楚 FIBEMATE 的验证体系：算法有哪些、各用什么方式验证、验证结果如何存证。
2. 让"100 份 TSR + 全绿 CI + KAT 10k"这类抽象数字变成看得见的拓扑关系。
3. 服务 8/31 开源后的第三方审计——审计人员一眼看到"算法 ↔ 证据"的映射。

## 4. 交互设计

| 交互 | 行为 |
|------|------|
| 拖拽旋转 | OrbitControls 环绕观察 |
| 滚轮缩放 | 深入内层 / 拉远全景 |
| 点击算法节点 | 弹出 HUD 卡片，显示验证状态 + 数据来源路径 |
| 悬停节点 | 放大 + 发光增强 |
| 点击证明链 | 显示该链的验证详情（如 TVLA t-statistic、KAT 轮数、TSR 编号） |
| 时间轴滑块 | v3.3 → v4.0 → v5.0，节点/壳层随版本点亮（对应 ROADMAP） |
