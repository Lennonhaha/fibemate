- **编辑委员会**: Bos, Celi, Kannwischer

## 拒稿理由 (编辑部)

### 1. 不够"自我完备" (Not Self-Contained)

> "缺乏完整的证明或令人信服的论证"

**分析**: VWZ 论文在以下方面存在论证缺口:
- 安全假设 (Assumption 1/2) 未充分证明其等价性或难解性
- Vandermonde 结构的代数特性与安全性的关联未完整推导
- 与已知 MCE 攻击模型的对比分析不够充分

### 2. 缺乏新颖性 (Lack of Novelty)

> "看起来不够'新且有趣'"

**分析**: VWZ 方案借用了 MCE (Matrix Code Equivalence) 框架，但:
- 核心构造与已有 MCE 方案共享类似结构
- 未提出新的密码学假设或突破性构造
- Vandermonde 公钥压缩技术是工程优化而非密码学创新

### 3. ePrint 不做同行评审/指导

> "IACR ePrint 不是期刊，不提供同行评审或技术指导"

**正确理解**: ePrint 并非 "门槛低"，而是 "无门槛但有基本质量预期"。编辑认为稿件未达到可存档水平。

## 实质判断

### 未曾被否定的 — 技术核心

| 方面 | 状态 |
|:---|:---|
| 数学构造正确性 | ✅ 未被质疑 |
| 代码实现 | ✅ 23/23 Rust 测试全绿，WASM 可运行 |
| TVLA 侧信道测试 | ✅ N=10,000 通过 |
| FPGA 硬件原型 | ✅ BRAM 求解器 5/5 |
| Hull 攻击评估 | ✅ 2^2080 不可行 |

### 被否定的 — 呈现与论证

| 问题 | 严重程度 | 可修复性 |
|:---|:---|:---|
| 安全证明不完整 | ⚠ 高 | 需要数月至数年深度研究 |
| 新颖性不突出 | ⚠ 高 | 需要新的数学构造或范式突破 |
| 与标准 MCE 方案区分度不足 | ⚠ 中 | 需要更清晰的差异化分析 |
| 论文结构问题 | ⚡ 低 | 一两天可修 |
| 文献综述不够 | ⚡ 低 | 几天可补 |

## 三角验证

| 判断源 | 结论 | 日期 |

**三方向一致**: 拒稿不是坏消息，是自我定位准确的外部确认。

## 行动决策

### 当前: 锁仓不投

- ePrint 投稿路径正式关闭
- 不再投期刊/会议/预印本
- VWZ 代码/测试/TSR 保留在 repo 中（工程价值）
- 未来如需学术发表，需要:
  1. 1-2 年同行反馈积累
  2. 安全假设的严格证明
  3. 与现有方案的差异化突破

### 备选: 改稿重投 (不推荐)

- 五个呈现问题可修复 (数天工作量)
- 但核心问题 (证明 + 新颖性) 仍需深度研究
- 有循环返工风险
- 与 6.28 决策冲突

## 经验教训

1. **ePrint 不是 "无门槛"**: 编辑对密码学稿件有基本质量预期
2. **安全证明是第一生产力**: 密码学论文的核心不是代码，是证明
3. **自我定位准确的价值**: 6.28 的锁仓决策正确，避免了反复投稿-拒稿循环
4. **工程与学术的界限**: FIBEMATE 的竞争力在工程实现，不在密码学理论创新
