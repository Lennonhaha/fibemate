# 木火通明模型嵌入天文分野系统 — 2026-08-14

## 目标
用户要求在木火通明架构可视化模型中嵌入成都/哈尔滨的天文分野信息，营造「天人合一」意境：分野 → 方位 → 护盾覆盖四方 → 安全防御。

## 天文数据（已核对）
- **井鬼 · 鹑首 · 未宫 · 成都（西南）**：井宿八星 + 鬼宿四星（共 12 星），古天文分野对应益州/西南
- **尾箕 · 析木 · 寅宫 · 哈尔滨（东北）**：尾宿九星 + 箕宿四星（共 13 星），对应幽州/东北
- 两宿在天球上形成西南↔东北对角，契合「护盾四方」叙事

## 嵌入元素
1. **天球系统**（半径 RA=10.0，包裹三层护盾球壳 R1/R2/R3）：
   - 三条天球纬圈（赤道带 + 两条倾斜圈），营造「天球」感
2. **两星宿群**：井鬼（蓝 0x60a5fa，12 星）/ 尾箕（金 0xeab308，13 星）
   - 星点用 Sprite + CanvasTexture（径向渐变辉光，AdditiveBlending）
   - 星宿连线：按环绕角排序后闭环连线，形成「古宿轮廓」
3. **分野连线弧**：QuadraticBezierCurve3 连接两星宿，中点外推到 RA*1.12 形成大圆弧
   - 沿弧流动的 60 个流光粒子（分野流光）
4. **分野标签**：Sprite 文字（井鬼·鹑首·未宫 / 尾箕·析木·寅宫 + 成都·西南 / 哈尔滨·东北）
5. **底部叙事条**（HTML）：天人合一 · 天象分野 ⟷ 密码护盾 + 两分野对照

## 关键修正（两处 bug）
1. **`pts.getPoint` 报错**：`curve.getPoints(120)` 返回数组，误当曲线对象调用 `.getPoint()` → 改存 `curve` 对象，用 `curve.getPoint(t, tmp)` 采样
2. **井鬼星宿跑出视野**：初版用黄道坐标映射（`toEcliptic`），把「西南」错误推到头顶 y≈8.8，超出相机视野（camera 在 0,6,16）→ 改用显式锚点球坐标：井鬼 (-5.8,3.4,-5.2)、尾箕 (5.8,-3.4,-5.2)，左上↔右下对角，都在视野内

## 视觉优化
- 金色标签（尾箕）与金色球体背景融合、对比度低 → 文字加深色描边（strokeText + lineWidth 8）+ 金色提亮为 0xfcd34d

## 技术约束
- 项目自托管 three 只有 three.module.js + OrbitControls.js，**无 CSS2DRenderer** → 文字标签全部用 Sprite + CanvasTexture（lwe-hardness 同法）
- Sprite 标签 aspect 按 512/128 缩放
