# FIBEMATE 工程风险分级整改清单

> 版本: v3.3 | 最后更新: 2026-07-22
> 定位: 8.31 开源前置整改 + 后续迭代优化 + 第三方审计对接
> 配套: [安全限制声明](./security-limitations.md)

## 风险分级标准

| 级别 | 定义 | 触发条件 |
|:---|:---|:---|
| **P0** | 高危阻塞风险 — 影响生产安全、存在漏洞隐患、阻碍开源发布、安全论证失效 | **必须立即整改，开源前清空** |
| **P1** | 中高工程风险 — 影响可复现性、自动化完整性、文档准确性 | 次优先级迭代整改 |
| **P2** | 常规优化风险 — 仓库规范、可维护性、社区生态 | 中长期迭代优化 |
| **P3** | 细节瑕疵 — 文案、命名、配置小问题 | 低优先级修复 |

## P0: 高危阻塞风险（开源前必改·2026-08-31 Deadline）

| ID | 风险项 | 根因 | 整改方案 | 完成时限 | 状态 |
|:---|:---|:---|:---|:---|:---|
| **P0-01** | 实验组件无编译期隔离，存在生产混入风险 | 仅运行时开关控制（`ENABLE_VWZ`/`ENABLE_LG`），无代码强隔离 | 增加编译期 Feature Flag，生产构建强制剔除 VWZ/LG 全部代码；CI 区分"生产构建产物"与"实验构建产物" | **2026-08-20** | ⬜ 待实施 |
| **P0-02** | FPGA 物理侧信道测试空白，安全论证断层 | CH340G 5V 电平不匹配 CPGA 3.3V 根因 | 更换 CP2102/FT232 设备；完成 ChipWhisperer 功耗/电磁测试；补齐 L9 安全证据 | **2026 Q4** | ⬜ 待硬件适配 |
| **P0-03** | ML-KEM 自定义实现隐蔽漏洞风险高（已降低） | 早期时域实现脱离 NTT 标准范式；内部自测无法全覆盖 | ✅ 2026-07-21 已重写为 FIPS 203 NTT 域实现；✅ noble + liboqs 双向 10,000 轮全量通过；固化跨库交叉验证 CI 门禁 | **2026-08-25** | ✅ 核心已解决，CI 门禁待固化 |
| **P0-04** | 废弃 TLS Path A 代码堆积冗余 | 生态兼容失败未清理归档（X25519MLKEM768 永久搁置） | 通过编译宏隔离废弃代码；归档无效脚本与产物；补充兼容失败详细复盘文档 | **2026-08-20** | ⬜ 待清理 |

## 整改验收标准

### P0 验收（开源前必达）

- [ ] 无生产代码污染 — `npm run build:prod` 产物中零 VWZ/LG WASM 文件和引用代码
- [ ] 无安全论证断层 — FPGA 物理侧信道至少完成第一轮 ChipWhisperer 数据采集
- [ ] 无标准兼容漏洞 — ML-KEM 跨库交叉验证 CI 门禁固化，任一 fail 阻断 PR
- [ ] 无编译打包风险 — 废弃代码通过编译宏隔离，不会出现在生产构建中

### P1 验收

- [ ] 全流程自动化 — FPGA/TLA+/VWZ 测试接入 Nightly CI
- [ ] 全文档同步 — 中英文 README、PROGRESS、CHANGELOG 无冲突
- [ ] 全构建可复现 — `npm ci && npm run build` 在 Linux/Windows/macOS 三端一致

### 通用验收

- [ ] 所有整改结果通过 CI 回归测试
- [ ] 关键整改 TSR 存证归档
- [ ] `risk-rectification.md` 更新为最新整改状态
