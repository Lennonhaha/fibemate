**FIBEMATE v3.3.0 is now open source**

A full-stack post-quantum cryptography engineering validation platform — from math to working code to FPGA bitstream to web visualization.

**What's inside:**
- ML-KEM-768 / ML-DSA-65 / SLH-DSA-128s (FIPS 203/204/205)
- SM2 / SM3 / SM4 (Chinese national standards)
- TLS 1.3 Hybrid KEM (X25519 + ML-KEM768)
- Post-quantum Double Ratchet with TLA+ formal verification
- FPGA Verilog RTL with BRAM simulation
- 25+ interactive visualizations at fibemate.net

**Every claim has a runnable test + timestamped evidence.** The full evidence chain is publicly auditable.

**Honest about limitations** — this is an engineering record, not production software. Known constraints are documented without gloss.
