## 1. 当前安全边界

### 1.1 参数空间

| 参数 | 值 | 说明 |
|------|-----|------|
| 安全参数 k | 2, 4, 8, 16, 32 | k=8 工程基准, k=16 过渡, k=32 目标 |
| 有限域 q | 3329 (NTT 素数) | 标准 ML-KEM 域，复用硬件乘法器 |
| 向量维度 N | 2k+1 | 签名空间维度 |
| 子空间维度 M | k+1 | 秘密/挑战维度 |
| 稀疏度 | rank-1 压缩 | pk N 元素 → 2k 种子, sig M 元素 → k 种子 |

### 1.2 安全假设层次

```
应用层: EUF-CMA 数字签名（无可信第三方，148/148 测试全绿）
  ↑ 归约
密码学层: VMQ-SPARSE（Vandermonde 矩阵二次型稀疏原像问题）
  ↑ 启发式
困难性层: 变体 Vandermonde 系统在有限域上的求解复杂度
```

### 1.3 已知攻击面

| 攻击类型 | 适用性 | 复杂度估计 (k=8) | 备注 |
|----------|:---:|------|------|
| 直接代数求解 | 理论可行 | ~2^73 | VMQ-SPARSE 归约待形式化证明 |
| 格基约减 (BKZ) | 未验证 | 未知 | 非标准格问题，非 LWE 语义 |
| Gröbner 基 | 理论可行 | 未知 | MQ 系统变体, F4/F5 复杂度待估算 |
| 量子算法 | 远未达规模 | 未知 | q=3329, N=17, 远小于 Shor/Grover 阈值 |
| 侧信道 (物理) | 潜在 | N/A | JS 实现非常数时间, FPGA 未做 TVLA |
| 暴力穷举 | 不可能 | ~q^k = 3329^8 ≈ 2^93 | 参数保护 |

## 3. 攻击模型分解

### 3.1 代数攻击路径

**阶段 1: Vandermonde 结构利用**

VWZ 的核心矩阵 V ∈ F_q^{N×N} 是 Vandermonde 矩阵（λ 幂）。攻击者可以用 O(N²) 时间显式写出 V 和 V⁻¹，但是否能简化签名伪造需进一步分析。

**阶段 2: 二次型稀疏性**

签名形式: σ = w₂ ∘ P₃(λ) + w₃，其中 P₃ 是 I₃ 索引集合上的 Lagrange 多项式。攻击者面临: 给定 pk（Vandermonde 投影），找到 (w₂, w₃) 满足验证方程。

**阶段 3: Gröbner 基**

将验证方程重写为 GF(3329) 上的多元二次系统:
- 未知数: 2(k+1) = 18 (k=8)
- 方程数: 2k+1 = 17 (k=8)
- 系统类型: 欠定（18 变元, 17 方程）

对多元二次欠定系统，Gröbner 基计算复杂度为:
- F4: O(n^(ω·d_reg)) 其中 d_reg 是正则度
- 小域 GF(3329) 上 degrevlex 排序优于 lex
- 需 Sage/FGb 实验确认实际 d_reg

### 3.2 格攻击路径

**编码方案**: 将 VMQ-SPARSE 签名验证方程编码为格中短向量搜索:

1. 扩展系数矩阵 A → 格基 B
2. 目标: 寻找短向量 v = (w₂, w₃, e) 满足 Av = t
3. BKZ-β 求解，β 取决于维度与模数

**关键未知量**:
- 格维度 d = f(k)
- BKZ-β 需求 = f(d)
- 是否有"异常短"向量可利用？

待用 lattice-estimator 量化验证。

### 3.3 量子攻击路径

| 算法 | 加速倍数 | k=8 复杂度 | k=16 复杂度 |
|------|:---:|------|------|
| Grover (暴力) | √N | ~2^46.5 | ~2^93 |
| HHL (线性系统) | O(log N) | O(poly(k)) | O(poly(k)) |
| 量子代数攻击 | 未知 | 未知 | 未知 |

量子代数攻击（量子 Gröbner 基）是一个活跃研究领域但尚无通用加速结果。

## 5. 已知限制与诚实声明

1. **VMQ-SPARSE 不是标准难题**: 它是项目自研构造，未经过长期同行评议
2. **安全归约不完整**: EUF-CMA 证明依赖 VMQ-SPARSE 在 ROM 下，但 VMQ-SPARSE 本身未归约到标准难题
3. **常数时间未验证**: JS 实现 / Rust WASM 均未做常数时间审计
4. **实验规模有限**: k=32 崩溃（α 碰撞问题）→ safe_alphas() 修复 → 但 k=32 完整测试未跑
5. **无大规模基准**: 仅 k=2~8 完整验证, k=16/32 待系统测试
