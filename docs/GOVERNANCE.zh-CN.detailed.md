## 1. 项目愿景

FIBEMATE 是一个后量子密码学（PQC）工程验证平台，旨在提供可执行的后量子密码学教科书和教育资源，帮助开发者理解和验证 PQC 算法的工作原理。

### 核心价值观

- **教育与验证优先**: 可读性和可验证性优先于极致性能
- **诚实透明**: 所有声明都有可运行的测试脚本和 TSR 证据链支撑
- **安全意识**: 明确告知用户当前实现的局限性和适用范围
- **开放协作**: 欢迎社区贡献和反馈

---

## 2. 项目定位

### 2.1 是什么

- **PQC 可执行教科书**: 通过可运行的代码理解 PQC 算法
- **工程验证平台**: 验证 PQC 实现的正确性和安全性
- **教育工具**: 用于教学和学习后量子密码学

### 2.2 不是什么

- **生产级密码库**: 不建议在生产环境直接使用
- **加密聊天应用**: 这是工程验证平台，不是聊天软件
- **性能优化库**: 性能不是首要目标

### 2.3 适用场景

✅ **适合**:
- 学习和理解 PQC 算法
- 验证 PQC 实现正确性
- 教育和培训
- 原型开发和测试

❌ **不适合**:
- 生产环境部署
- 高性能应用
- 需要第三方审计的场景
- 处理敏感数据

## 6. 版本管理

### 6.1 版本号规则

遵循语义化版本（SemVer）: `MAJOR.MINOR.PATCH`

- **MAJOR**: 不兼容的 API 变更
- **MINOR**: 新功能，向后兼容
- **PATCH**: Bug 修复，向后兼容

**示例**:
- `v3.3.0`: 五层评估体系交付
- `v3.3.1`: Bug 修复
- `v4.0.0`: 架构重大变更

### 6.2 发布流程

**发布前检查清单**:
- [ ] 所有测试通过（480/480）
- [ ] KAT 验证通过（100%）
- [ ] TVLA 测试通过（36/36）
- [ ] 文档更新
- [ ] CHANGELOG 更新
- [ ] 版本号更新
- [ ] Tag 创建

**发布后**:
- [ ] GitHub Release 发布
- [ ] 官网更新
- [ ] 社交媒体公告
- [ ] TSR 存证

### 6.3 支持策略

**活跃支持**:
- 最新稳定版本（v3.3.0）
- 安全更新 + Bug 修复

**维护支持**:
- 上一个稳定版本
- 仅安全更新

**不再支持**:
- 更早版本
- 建议升级到最新版本

## 7. 安全治理

### 7.1 安全策略

参考 `SECURITY.md`

**关键原则**:
- 所有安全漏洞公开披露
- 优先修复高危漏洞
- 提供明确的升级路径
- 维护 TSR 证据链

### 7.2 安全审计

**内部审计**（持续）:
- TVLA 时序测试
- KAT 向量验证
- 依赖漏洞扫描
- 代码审查

**外部审计**（计划中）:
- Q4 2026: 启动第三方审计
- 范围: ML-KEM-768/1024, ML-DSA-65, SM2/SM3/SM4
- 目标: 通过独立安全审计

### 7.3 已知局限性

参考 `docs/security-limitations.md`

**明确声明**:
- 纯 JS 实现非常数时间
- C addon 未经过 fuzzing
- 侧信道仅软件仿真
- 无 FIPS 140-3 认证
- 无第三方审计
