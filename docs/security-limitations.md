# FIBEMATE 安全限制与诚实声明

> 版本: v3.3 | 最后更新: 2026-07-22

## 本文目的

本文档明确陈述 FIBEMATE 的安全边界、已知限制和不适用范围。**诚实的工程必须声明自己做不到什么**，而不是靠模糊措辞暗示安全增益。

---

## 1. 密码学安全边界

### 1.1 ML-KEM-768 — NIST FIPS 203 合规

| 声明 | 内容 |
|:---|:---|
| **安全保障** | NIST Category 1: ≈128-bit 经典 / ≈64-bit 量子 |
| **算法基础** | Module-LWE (格问题, BKZ 归约) |
| **实现** | NTT 域, FIPS 203 线格式, 纯 JavaScript (Node.js 22+) |
| **认证** | Noble 200/200 交叉验证, liboqs 10000/10000 |

**限制**:
- JavaScript 运行时不提供恒定时间保证（JIT 编译器优化不可控）
- 不可用于共享内存/多租户环境（侧信道风险）
- 不支持 HSM/TEE 集成 — 密钥存在进程内存中
- 未经过第三方安全审计

### 1.2 SM2/SM4 — 国密套件

| 声明 | 内容 |
|:---|:---|
| **安全保障** | SM2: 256-bit ECC; SM4: 128-bit 分组密码 |
| **侧信道加固** | k-masking (320-bit 随机掩码), 费马小定理模逆 |
| **TVLA 验证** | N=5000 |t|<5 (固定 vs 随机 t-test) |

**限制**:
- TVLA 仅覆盖 CPU 软件层面，未测试物理侧信道
- SM4 实现不支持 SCA 加固（无 boolean masking）
- 不支持 GB/T 32918-2016 全部参数集（仅推荐曲线）

### 1.3 VWZ — 后量子签名实验方案

| 声明 | 内容 |
|:---|:---|
| **状态** | 🔬 实验方案, **不可用于生产** |
| **安全等级** | ≈73 bits (k=8), 未经验证 |
| **已知攻击** | Hull 攻击 2^2080 (不可行), 但存在未知代数结构风险 |

**限制**:
- 安全假设未被长期同行评审验证
- 无第三方密码分析文献
- 默认关闭于主链路中
- 不宣称等同于 NIST PQC 安全等级

### 1.4 LookingGlass v2 — 混淆层实验

| 声明 | 内容 |
|:---|:---|
| **状态** | 🔬 独立实验仓库 |
| **定位** | 逆向工程屏障, 不增强 LWE 数学硬度 |

**限制**:
- 等变 LWE 混淆不改变 BKZ 归约复杂度
- d=5~8 层有实际工程上限
- 不用于生产链路
- 禁止称之为 "安全增益" — 仅 "逆向成本"

## 2. 实现安全限制

### 2.1 JavaScript 运行时

- **非恒定时间**: V8/JSC 的 JIT 可能优化掉分支或引入时序差异
- **内存管理**: GC 可能泄漏密钥擦除时机；无 `SecureZeroMemory`
- **侧信道**: 无 assembly-level masking；无 Spectre/Meltdown 缓解

### 2.2 浏览器环境

- **IndexedDB**: 密钥持久化存储，但不能防止浏览器扩展/恶意脚本访问
- **WASM**: 提供部分内存隔离，但不保证恒定时间
- **CSP**: 网站配置 XSS 缓解，但不防止物理访问

### 2.3 服务端 (reg-server)

- **内存存储**: 无持久化，重启即丢所有用户/OPK 数据
- **无认证**: WebSocket 无客户端认证机制
- **无速率限制**: 可能被 DoS
- **不用于生产**: reg-server 是协议原型，非生产级消息服务器

## 3. 环境与运维

### 3.1 当前部署

| 项目 | 风险 |
|:---|:---|
| 单服务器 (ECS) | 单点故障 |
| Let's Encrypt 证书 | 90 天旋转，依赖 ACME |
| 无 HSM | 私钥无硬件保护 |
| 无监控 | 无入侵检测/安全事件响应 |
| Bus Factor = 1 | 单人维护 |

### 3.2 网络

- GFW 可能阻断 GitHub ↔ 服务器直连
- `fibemate.link` 域名为国内备案域名，可能受限
- 无 CDN/DDoS 防护

## 4. 合规与法律

### 4.1 密码学出口

- ML-KEM-768: 不受 EAR 管控（NIST 标准）
- SM2/SM4: 国密算法，中国境内可用，跨境使用需合规审查

### 4.2 国密合规

- 本项目的 SM2/SM4 实现为**技术验证目的**
- 未经国家密码管理局认证
- 不可用于商用密码产品（需 GM/T 认证）

### 4.3 开源许可

- MIT License
- 代码可自由使用、修改、分发，但无担保

## 5. 不适用范围

密码学套件 **不可用于**：

- 军事/国防通信
- 生命攸关系统（医疗设备、航空电子）
- 金融核心交易系统
- 政府机密数据保护
- GDPR/HIPAA 合规场景（无审计跟踪）

密码学套件 **可适用于**：

- 学术研究
- 教学演示
- 原型验证
- 开源社区评审
