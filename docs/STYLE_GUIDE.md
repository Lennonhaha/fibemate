# FIBEMATE 文档风格规范（STYLE_GUIDE）

> 适用范围：`docs/`、`www/docs/`、根目录 `.md`、`www/index.html` 等所有面向读者的中文文档。
> 目的：统一标点与术语写法，避免中英文标点混用、裸 `&` 误用。
> 最后更新：2026-08-13

## 一、统一标点规范

| 场景 | 规范 | 示例 |
|------|------|------|
| 文档标题分隔 | 用 `·` | `项目治理 · 决策流程 · 维护者职责` |
| 并列关系（中文） | 用 `、` 或 `与` | `依赖与安装、可复现构建` |
| 范围表示 | 用 `→` 或 `至` | `v1.0 → v3.3` 或 `v1.0 至 v3.3` |
| 代码 / 术语 | 用反引号 `` ` `` | `` `CITATION.cff` `` |
| 中文引号 | 用 `“”` | `“诚实标注纯 JS 边界”` |
| 注释说明 | 用 `「」` | `「仅供教学演示，不推荐生产」` |

## 二、禁止 / 替换规则

| 修正项 | 替换规则 | 示例 |
|--------|----------|------|
| 裸 ` & `（中文并列） | `&` → `与` / `·` / `、` | `依赖 & 安装` → `依赖与安装` |
| 半角引号（中文语境） | `"xxx"` → `“xxx”` | `"诚实标注"` → `“诚实标注”` |
| 连字符当分隔（中文） | ` - ` → ` · ` | `灾难恢复 - 备份策略` → `灾难恢复 · 备份策略` |
| 尾部冗余标点 | 删除 | `事件处置 · 上报流程，` → `事件处置 · 上报流程` |

## 三、必须保留（不可替换）

以下场景中的 `&`、`-`、`"` **一律保留**，不得按第二节规则替换：

1. **HTML 实体**：`&nbsp;` `&amp;` `&lt;` `&gt;` `&quot;` `&apos;` `&#数字;`
2. **位运算 / 逻辑运算**：`&&` `&` `|` `^` `~`（代码块内）
3. **URL 查询参数**：`?a=1&b=2`、`&redirect=`
4. **官方英文术语**：NIST CSF 的 `Detection & Analysis`、`Containment, Eradication & Recovery` 等——括号内引用原文时保留 `&`
5. **代码块 / 内联代码**：反引号与代码围栏内的内容一律不动

## 四、执行口径

- **纯中文标题 / 描述**：按第二节统一。
- **中英混排**：中文部分统一，括号内英文术语保留原文。
- **有疑问时**：优先「不破坏术语准确性」，宁可保留原文，也不要为统一而改错。

## 五、代码安全：正则 ReDoS 检查（编写新正则前必读）

> 适用范围：所有新写的正则表达式（尤其 `.js` / `.ts` 代码，不论是否面向读者）。

**禁止使用的危险模式**（回溯灾难 / ReDoS，攻击者可用恶意输入导致 CPU 飙高）：

| 危险模式 | 说明 | 安全替代 |
|----------|------|---------|
| `.*$` / `.+$`（未约束） | `.*` 与 `$` 组合，长输入下指数级回溯 | 用 `split()` / 字符类 `[^/]*$` |
| `(.+)+` / `([a-z]+)+`（嵌套量词） | 嵌套量词是 ReDoS 典型根源 | 拆成单层 |
| `(a|a)+`（重叠分支） | 分支重叠导致重复匹配 | 消除分支重叠 |

**编写新正则时的自查清单**：
1. 是否有 `.*` / `.+` 紧邻锚点 `$`？→ 改用字符类或 `split()`
2. 是否有嵌套量词 `(...+)+`？→ 拆单层
3. 是否在用户可控输入上执行？→ 优先用非正则的字符串方法（`split` / `includes` / `startsWith`）

**示例**（2026-08-13 实际修复）：
```js
// ❌ ReDoS：长路径输入会回溯
l.replace(/^https?:\/\//, '').replace(/\/.*$/, '')
// ✅ 等价无回溯
l.replace(/^https?:\/\//, '').split('/')[0]
```
