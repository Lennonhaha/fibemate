## 1. VWZ 加强方向审查

### 1.1 方向一（打破 rank-1，设计新张量）— 正确但需归约

攻击根因：验签方程 `t[i1] = (u[i1]·w2)(v[i1]·w3)` 因切片 rank-1 退化为两个线性因子乘积。

- **满秩切片**：若 `ψ[i1]` 满秩，验签变为双线性系统 `w2ᵀψ[i1]w3 = t[i1]`（对全部 i1），接近 MQ/多变量二次问题，攻击显著变难——**方向正确**
- **关键约束**："满秩"本身不保证难解，必须对**该双线性系统的求解复杂度做形式化归约**（无 rank-1 可分性 ≠ MQ-hard 证明）
- **混合多个 Vandermonde 张量**：`ψ[i1] = Σⱼ λⱼ uⱼ⊗vⱼ` 使切片秩升至 r>1，双线性方程变成 r 项之和，攻击不再是简单线性分解——但需证明不重新引入其他代数结构（如对称性、低秩因子化）
- 本质：这是**设计新方案**，需完整重新分析

### 1.2 方向二（增 k / 矩阵扰动）— 两个子项均有缺陷

**增 k 无效**：本次攻击是多项式时间 O(k³)，已实证 k=16（声称 ~139 bits）36/36 伪造。参数放大只改变常数因子，**安全位不随 k 增长**，这是实测结论而非推断。

**矩阵扰动有根本缺陷**：
- 确定性噪声：公钥公开，攻击者可直接减去恢复精确张量
- 随机噪声：破坏 trapdoor 逆变换的**精确性**，合法验签会失败（假阴性）
- 除非改为概率性验签——那是新方案，且需重新设计抽样与容错

### 1.3 VWZ 务实建议

同意用户结论：短期记录并冻结改动，长期按方向一重新设计。**额外警告**：即便方向一落地，验签系统的欠定性（2(k+1) 未知数 vs 2k+1 方程）与稀疏 target 结构仍在，新方案必须针对「双线性系统求解 + 稀疏 target」的组合威胁建模。

## 2. LG v2.3 加强方向审查

### 2.1 P0 引入跨字节扩散 — 正确方向，但 MixColumns 单独不够

**实证 1：固定 MixColumns 可被解析剥除**（`attack/lg_hardening_proof.py`）

构造 `hardened_fixed = MDS(confuse_full(data, seed))`（用户 P0 方案 C 的直接实现，MDS 为 AES 标准矩阵）：

```
单字节扰动影响字节数分布: [4]            ← 原逐字节攻击失效（期望值）
[攻击成功] 剥除 MDS 后原方法 100% 命中    ← 关键：攻击复杂度不变
```

攻击流程：
1. 观察到扰动影响 4 字节 → 原逐字节表方法失效
2. **但 MDS 矩阵公开且固定** → 攻击者对 oracle 输出应用 `MDS⁻¹` 剥除线性层
3. 剥除后回到**原始 confuse 混淆**，用原方法（扰动定位 σ + 逐字节扫描）100% 恢复
4. 端到端验证：模型预测再套一次 MDS，与真实 oracle **100% 一致**

**结论**：固定公开的扩散矩阵无法提高安全性——线性层可逆、可剥除，攻击复杂度保持 O(N·256)。

### 2.2 实证 2：seed 化组矩阵 — 实质提升但扩散仍限组内

构造 `hardened_seeded`：每 4 字节组用 seed 派生的随机可逆 GF(256) 矩阵：

- 矩阵未知 → 无法剥除（区别于实证 1）
- **但扰动仍只影响组内 4 字节**（扩散范围未达全块）
- 攻击退化为逐组暴力：O((N/4)·256⁴) ≈ 4e9 级

**判定**：从 O(N·256) 升到 4e9 级是实质提升，但扩散粒度仍限于 4 字节组，**不是全块扩散**。

### 2.3 实证 3：seed 化全块可逆线性混合 — 真正达标

构造 `feistel_full`（GF(256) 双三角可逆线性层，seed 派生系数）：
- pass1 下三角 + pass2 上三角，每个输出字节依赖全部 N 个输入字节

实测（N=64，10 个随机输入各扰动 1 字节）：

```
单字节扰动影响字节数: 最小 62, 最大 64     ← 近全块扩散达标
```

- 原攻击（σ 定位）失效（扰动影响 62-64 字节）
- 系数矩阵 seed 派生、攻击者未知 → 无法像固定 MDS 那样解析剥除
- 恢复攻击退化为 GF(256) 上的线性代数求解（需选明文恢复 N×N 矩阵），或对 seed 暴力搜索

**判定**：这才是能实质阻断黑盒攻击的扩散层级。注意：线性层本身仍可用选择明文+线性代数恢复，工程上应与逐字节非线性层交替 ≥2 轮（见 2.4），把恢复问题推向非线性系统。

### 2.4 推荐方案：seed 依赖的全块扩散 + 逐字节层组合

```
premix(seed) → Wreath(seed) → [Feistel/全矩阵扩散, seed 派生密钥] → postmix(seed)
```

要点：
1. **扩散层必须 seed 依赖且全块**（随机可逆矩阵或 Feistel），不能是固定 AES 矩阵
2. 扩散层密钥不得复用 seed 直接裸值（用 ChaCha/AES 派生）
3. 逐字节层与扩散层交替 ≥2 轮，防止"剥除一侧"的简化攻击

### 2.5 P1 种子空间 — 对黑盒重构无效（重要认知修正）

本次攻击**从不猜 seed**：单字节扰动定位 σ 后逐字节扫描重建映射，完全数据驱动。**seed 空间增大不影响黑盒重构复杂度**。

seed 空间只在以下场景才成为安全瓶颈：
- 扩散层 seed 依赖时（此时才需要抗暴力搜索）
- 攻击者已获得映射表、需要推断 seed 复用时

因此 P1 必须与 P0 的 seed 化扩散**组合实施**才有意义，单独增大 seed 概率无用。

## 3. 结论

1. **VWZ**：方向一是唯一出路，但必须对双线性系统做形式化归约；方向二两个子项均不可行
2. **LG**：MixColumns 单独挡不住（固定可剥除），seed 化组矩阵是提升但仍限组内，**全块 seed 相关扩散**才是阻断黑盒攻击的关键
3. **组合拳**：扩散（全块 seed 依赖）+ 密钥派生（ChaCha/AES）缺一不可；P1 是 P0 的前提而非替代
