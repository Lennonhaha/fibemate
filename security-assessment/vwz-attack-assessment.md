# VWZ 签名方案第三方攻击评估报告

**组件**: VWZ hash-and-sign signature (rust/vwz-sign-wasm)
**分支**: `experimental/vwz-lg`, commit a0ef4e5
**实现依据**: IACR 2025/624 — *Trapdoor one-way functions from tensors*
**评估角色**: 独立第三方攻击者（仅持公钥与消息，无任何私钥/陷门信息）
**评估日期**: 2026-08-16
**结论**: **完全攻破 (Total break)** — 多项式时间密钥无关伪造签名

---

## 1. 攻击摘要

VWZ 签名方案的验签仅检查一个**公开可计算的双线性方程**：

```
verify(pk, msg, (w2, w3)):
    t = hash_to_sparse_target(msg, k)          # 公开哈希，稀疏，weight = k+1
    return  public_tensor_eval(pk, w2, w3) == t
```

其中：

```
public_tensor_eval(pk, w2, w3)[i1] = Σ_{i2,i3} ψ[i1][i2][i3] · w2[i2] · w3[i3]
```

- 公钥 `ψ` 是尺寸 `(2k+1) × (k+1) × (k+1)` 的张量，域 F_3329
- 签名 `(w2, w3)` 均为长度 `k+1` 的向量
- 未知数 2(k+1) 个，方程 2k+1 个，**欠定一个自由度**

**攻击核心观察**：公钥张量的每个切片 `ψ[i1]`（一个 `(k+1)×(k+1)` 矩阵）**必为 rank-1**。

证明：由 trapdoor 生成过程（`trapdoor.rs`），`ψ[i1] = x1[i1] · X2ᵀ · ϕ[i1] · X3`，其中 `ϕ[i1]` 为 Vandermonde 外积张量切片 `ϕ[i1][i2][i3] = λ_{i1,2}^{i2} · λ_{i1,3}^{i3}`（即 rank-1 矩阵），`X2, X3` 为可逆矩阵，`x1[i1]` 为标量。可逆矩阵左乘/右乘与标量倍乘均不改变矩阵的秩。

由此，验签方程可分解为**两个线性因子之积**：

```
ψ[i1] = u[i1] ⊗ v[i1]        (rank-1 分解，仅用公钥即可提取)
t[i1] = (u[i1]·w2) · (v[i1]·w3)      ∀ i1 = 0..2k
```

---

## 2. 攻击算法（多项式时间，无需私钥）

输入：公钥 `ψ`，消息 `msg`。输出：伪造签名 `(w2, w3)`，通过官方 `verify()`。

1. **分解切片**：对每个 `i1`，将 rank-1 矩阵 `ψ[i1]` 分解为 `u[i1] ⊗ v[i1]`。
   取第一个非零列作为 `u[i1]`，并用任一非零行确定 `v[i1]`。

2. **划分位置**：`Z = {i1 : t[i1] = 0}`（共 k 个零位置），`S = {i1 : t[i1] ≠ 0}`（共 k+1 个非零位置）。

3. **消去零位置**：解齐次线性系统
   ```
   u[i1]·w2 = 0   for all i1 ∈ Z
   ```
   k 个方程，k+1 个未知数 ⇒ 必然存在非零解 `w2`（1 维解空间）。
   此时对 `i1 ∈ Z` 自动有 `t[i1] = (u[i1]·w2)(v[i1]·w3) = 0`，与 `w3` 无关。

4. **满足非零位置**：解仿射线性系统
   ```
   v[i1]·w3 = t[i1] / (u[i1]·w2)   for all i1 ∈ S
   ```
   k+1 个方程，k+1 个未知数，通常唯一解 `w3`（存在性由哈希目标结构保证）。

5. **验证**：直接计算 `public_tensor_eval(pk, w2, w3)` 是否等于 `t`。

**复杂度**：`O(k³)` 次域运算（两次线性方程组求解），对任何 `k` 均为多项式时间。

## 4. 根本原因

安全设计假设的「张量陷门单向性」在边界格式下失效：

1. **公钥张量泄露了 rank-1 切片结构**。Vandermonde 张量 `ϕ` 的切片 rank-1 属性经基底变换后**保持不变**（可逆矩阵不改变秩），导致公钥可直接分解出 `u[i1] ⊗ v[i1]`。

2. **验签方程退化为一维乘积结构**。双线性方程 `(u·w2)(v·w3) = t[i1]` 将两个签名分量解耦：先固定 `w2` 消掉所有零位置约束，剩余方程对 `w3` 变为纯线性系统。

3. **稀疏目标（weight k+1）恰好提供了 k 个零位置约束**，使 `w2` 的求解成为欠定齐次系统（必有非零解），再以剩余 k+1 个非零位置唯一确定 `w3`。

本质上：签名函数作为双线性映射，其「陷门」只是提供了求解一个**公开可解的线性代数问题**的捷径，而问题本身无需陷门即可在多项式时间内求解。

---

## 5. 影响

- **签名伪造**：任何持有公钥的攻击者可为任意消息生成通过验证的签名，无需知道 `(Λ, X1, X2, X3)` 陷门。
- **不可伪造性 (EUF-CMA) 完全丧失**：这是签名方案最基本的安全属性。
- **不区分参数档位**：声称 ~73 bits (k=8) 与更大参数均被多项式时间攻击覆盖，参数增大无法修复。

---

## 6. 修复建议（供参考）

- 重新设计验签方程，避免可分解为 rank-1 切片乘积；边界格式 `k1=k2+k3` 下的 Vandermonde 结构是攻击根源。
- 或将公钥做不可逆混合（如随机线性组合多切片），破坏 rank-1 可分解性——但需重新论证安全性，不能依赖「难以分解」的启发式假设。
- 在方案通过严谨的安全性归约（如对抗多项式插值/代数攻击）之前，**禁止用于任何签名用途**。
