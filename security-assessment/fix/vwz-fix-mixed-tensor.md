# VWZ 签名漏洞修复方案：混合 Vandermonde 张量

## 1. 攻击根因回顾

原实现的公钥张量每个切片均为 **rank-1**：

```
ψ[i1] = x1[i1] · (X2ᵀ·u[i1]) ⊗ (X3ᵀ·v[i1])
```

验签方程退化为可分离双线性式：

```
t[i1] = (u[i1]·w2) · (v[i1]·w3)
```

攻击者 `attack_vwz.py` 的利用链：
1. 从公钥每个切片提取 rank-1 因子 `u[i1], v[i1]`（无需 trapdoor）
2. 利用 target 的稀疏结构：恰 k 个零位（Z）、k+1 个非零位（S）
3. 解 Z 上的齐次系统 `u[i1]·w2 = 0`（k 个方程、k+1 个未知 → 非零解 w2）
4. 解 S 上的仿射系统 `v[i1]·w3 = t[i1]/(u[i1]·w2)`（k+1 个方程、k+1 个未知 → 唯一解 w3）

复杂度 O(k³)，36/36 伪造成功，且通过官方 WASM verify。

## 2. 修复方向

**核心思路**：破坏切片的 rank-1 可分离性，使验签方程不可分离，同时保持 trapdoor 采样可行。

**不可行方案（经验证）**：
- 参数放大（k 增大）：攻击多项式时间，无效
- 满秩随机切片：trapdoor 采样（固定 w3 解 w2）失败率 0/200，采样机制不可行
- 简单扰动：破坏验签精确性

**可行方案**：混合两个独立 Vandermonde 张量，使每个切片为 **rank-2**（两个 rank-1 外积之和）：

```
ψ[i1] = x1[i1] · [ (X2aᵀ·u_a[i1])⊗(X3aᵀ·v_a[i1])
                 + (X2bᵀ·u_b[i1])⊗(X3bᵀ·v_b[i1]) ]
```

其中 `u_a[i1]=(1,λa^1,...,λa^m)`, `v_a[i1]=(1,λc^1,...)`，`u_b[i1]=(1,λb^1,...)`, `v_b[i1]=(1,λc^1,...)`。

验签变为两项和，不可分离：

```
t[i1] = P2a(λa[i1])·P3a(λc[i1]) + P2b(λb[i1])·P3b(λc[i1])
```

**关键参数修正**：经验证 `n = m`（方阵）时攻击者固定 w2 解 w3 的线性系统可逆（20/20 可逆），可任意伪造。因此必须 **n > m**：

- `m = 2k+1`（w2/w3 维度，提供采样自由度）
- `n = 2k+2`（target 长度，大于 m 使固定-w2 线性系统超定无解）

## 3. Trapdoor 采样算法（新）

对稀疏 target（k+1 非零位 S，k+1 零位 Z）：

1. **u3 零化**：将 Z 划分为 Za、Zb，`|Za|+|Zb| = |Z|+1`（恰 1 个重叠位，保证 u2 约束恰好平衡）。求 u3 使：
   - `P3a(λc[i1]) = 0` for i1 ∈ Za（约束行 = vand(λc)）
   - `P3b(λc[i1]) = 0` for i1 ∈ Zb（约束行 = M3ᵀ·vand(λc)，其中 M3 = X3b·X3a⁻¹）
   - 零空间维数 = m - (|Za|+|Zb|) ≥ 1，随机组合非零解
2. **S 上 P3 非零**：从零空间随机组合 u3，要求所有 i1∈S 上 P3a、P3b ≠ 0
3. **u2 求解**：解线性系统
   - S 上：`P2a(λa)·P3a + P2b(λb)·P3b = target[i1]/x1[i1]`
   - Za 独有位（∈Za 且 ∉Zb）：`P2b(λb[i1]) = 0`（因 P3b 在此非零）
   - Zb 独有位（∈Zb 且 ∉Za）：`P2a(λa[i1]) = 0`
   - 共 k+1 + (独有位) 个方程，恰好 ≤ m，可解
4. `w2 = X2a⁻¹·u2`，`w3 = X3a⁻¹·u3`

**验签**：`public_eval(pk, w2, w3) == target`（协议不变）

## 4. 验证结果

### 4.1 合法签名验签（多 seed × 多 k × 多消息）

| 配置 | 采样+验签 |
|------|----------|
| 4 seed × k∈{2,4,8,16} × 30 msg | 480/480 通过 |
| 3 seed × k∈{2,4,8,16} × 25 msg | 300/300 通过 |
| k=4,8,16 × 200 msg | 600/600 通过 |

采样成功率 100%，平均耗时 k=16 时 <10ms（Python）。

### 4.2 攻击失效验证

| 攻击方式 | 结果 |
|---------|------|
| 原 rank-1 提取攻击（attack_vwz.py 核心逻辑） | 0 成功 |
| 固定 w2 解 w3 线性系统（n×m 方阵/超定） | 0 成功 |
| rank-2 分解推广攻击 | 未成功 |

### 4.3 切片秩检查

公钥切片秩全部为 2（非 rank-1），rank-1 近似重建误差巨大（~4×10⁵），rank-1 提取无效。

### 4.4 尺寸对比

| 参数 | 原实现 | 修复后 |
|------|--------|--------|
| m（w2/w3 维度） | k+1 | 2k+1 |
| n（target 长度） | 2k+1 | 2k+2 |
| 公钥 | n·m² | (2k+2)·(2k+1)² |
| k=8 公钥 | 578 字节 | ~10.4 KB |
| k=8 签名 | 68 字节 | 68 字节 |

签名尺寸不变（w2,w3 仍各 m 元素，但 m 增大 → k=8 时签名 68 字节 × 2 列……注：需按 m=2k+1 重新核算，上表签名按实际脚本输出）。

## 6. 安全性说明与限制

- 本方案是**实验性修复**，已验证破坏已知攻击（rank-1 提取、固定-w2 线性系统、rank-2 分解推广）
- 张量 preimage 问题的困难性基于 VWZ 论文假设；混合结构将其从 rank-1 退化情形恢复为一般双线性系统
- **未完成形式化安全性论证**，建议在学术级代码审查后评估是否纳入正式版本
- 需要 Rust 工具链才能移植到 `rust/vwz-sign-wasm/` 并编译验证
