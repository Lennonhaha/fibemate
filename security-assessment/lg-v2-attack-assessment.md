# LookingGlass v2.2.3 第三方黑盒攻击评估报告

**组件**: LookingGlass v2 (www/crypto/lgv2, lookingglass_v2_bg.wasm)
**分支**: `experimental/vwz-lg`, commit a0ef4e5
**评估角色**: 独立第三方攻击者（纯黑盒 oracle，仅调用 `lgv2_confuse`/`lgv2_deconfuse`，无反汇编、无源码、无 Frida、无 Angr）
**评估日期**: 2026-08-16
**结论**: **完全可逆 — 100% 精度黑盒重构**。混淆变换为「逐字节 S-box + 位置置换」的组合，纯黑盒采集可完整恢复正逆映射。

---

## 1. 攻击摘要

LG v2.2.3 的 `lgv2_confuse(data, seed)` 在**单字节扰动**下表现出决定性结构特征：

- 翻转任意单个输入字节，**恰好影响 1 个输出字节**（256/256 输入位置全部如此）
- 该字节映射是 256→256 **双射**（S-box 置换，非仿射、非 XOR 线性）
- 不存在跨字节扩散（wreath 层在 I/O 层面并未造成字节间耦合）

由此推断并验证：整个混淆变换可分解为

```
y[σ(j)] = S_j( x[j] )     for all j = 0..255
```

其中 σ 是输出位置置换（seed 相关），S_j 是每个字节独立的 256 项 S-box 表。

---

## 2. 攻击算法（纯黑盒）

输入：`lgv2_confuse` oracle，seed。输出：完整正/逆映射。

1. **基准**：查询 `cbase = confuse(0, seed)`。
2. **恢复置换 σ**：对每个输入位置 j，置 `x[j]=1`（其余 0），查询输出，与 `cbase` 比对，唯一变化的输出位置即 `σ(j)`。
3. **恢复 S-box**：对每个 j，遍历 `x[j] = 0..255`，记录 `S_j[v] = y[σ(j)]`。校验 256 项全不同（双射）。
4. **正向模型**：`y[σ(j)] = S_j[x[j]]`。
5. **逆向模型**：`x[j] = S_j^{-1}[y[σ(j)]]`。

**查询预算**：`1 + N + 256·N` 次 oracle 调用（对 N=256 约 6.6 万次），每次调用 256 字节。

---

## 3. 实验结果

| seed | 正向模型精度 | 逆向（反混淆）精度 |
|:---:|:---:|:---:|
| 777 | 100.00% | 100.00% |
| 0 | 100.00% | 100.00% |
| 123456789 | 100.00% | 100.00% |
| 2^40+999 | 100.00% | 100.00% |

- 块长 N=64 与 N=256 均成立（**长度无关**）
- 任意长度 roundtrip（16~512）官方自洽（deconfuse 正确）
- 对随机输入 50 次 × N 字节全量比对，**零误差**

---

## 4. 根本原因

1. **逐字节独立 S-box**：混淆核心等价于每字节查表，字节间无扩散。任何逐字节 S-box 都能通过 256 次单字节扫描完整恢复，这是密码学常识级弱点。
2. **位置置换不提供混淆强度**：σ 只是打乱输出字节顺序，通过"单字节扰动定位"可逐一还原，无需猜测。
3. **seed 仅是参数化开关**：不同 seed 只是生成不同 (σ, S_j) 表，恢复算法对任意 seed 同复杂度，攻击成本不随 seed 提升。

换言之，LG v2.2.3 的混淆强度等价于一个 256×256 的静态查找表（外加位置置换），属于**逐实例可枚举/可拟合**的范畴。官方 `attack/README` 预期"Frida/Angr 能够攻破"，实际攻击比 Frida/Angr 更简单——纯黑盒代数重构即可。

---

## 5. 影响

- **混淆完全失效**：攻击者用 ~6.6 万次 oracle 调用即可获得与 `deconfuse` 等价的逆向能力，无需密钥、无需反汇编。
- **不提供任何密码学强度**：符合官方自身定位（"仅逆向混淆，不提升 LWE 安全位数"），但需明确——其混淆也**不提供可度量的静态分析对抗强度**，逐字节查表结构在符号/代数分析下是透明的。
- **ML-KEM binding（lgv2_bind_kem）**：绑定为 `混淆输出 XOR Keccak-256(...)`，一旦混淆被还原，绑定退化为纯 XOR mask，可被常规手段剥离（未单独攻击，见 §7）。

## 7. 未覆盖 / 保留项

- `lgv2_confuse_ex` / `confuse_full`（session_key、ML-KEM binding 变体）未单独攻击；其附加层为 XOR mask 类，预期可剥离。
- 官方模拟层（collect-samples.py 的 XOR+S-box+FY 模型）与实际 WASM 语义不一致（WASM 是逐字节 S-box + 位置置换，模拟层更复杂），本报告以**真实 WASM 黑盒结果**为准。
- 官方 `real-wasm-findings.md` 描述的"前 48 维活跃 / 208 维透传"来自另一构建（底层 `apply_forward` 接口的 v2.2.3 开发版），与 www/crypto/lgv2 的字节级接口实现不同；本报告攻击对象为仓库内预编译 `lookingglass_v2_bg.wasm`（`lgv2_version()` 自报 "LG v2.2.2"，CLI 标注 baseline v2.2.3）。
