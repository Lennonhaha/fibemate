按 VMProtect 路线图执行阶段 1（基础强化）：解决 Wreath 活跃维度仅 48/256 字节的问题。

## 核心方案
XOR-Keystream Pre/Post-Mix：
```
数据 → XOR-keystream(premix) → Wreath(7层) → XOR-keystream(postmix) → 全字节覆盖
```
- Premix: XorShift64 PRNG 生成每个字节的 XOR 掩码，覆盖全部 256 字节
- Postmix: 同样是 XOR（XOR 是自身逆），使 premix 完全可逆
- 覆盖：Premix 256/256 + Wreath 48/256 = **全字节**
