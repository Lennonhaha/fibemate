🕐 可信时间戳存证

什么是可信时间戳？

本项目为核心代码文件申请 RFC 3161 可信时间戳，用于证明文件在某一时刻已经存在。签发机构为 FreeTSA 与 DigiCert；令牌内是否内嵌签名证书逐文件不同，见 归属表。

时间戳遵循 RFC 3161 标准。全仓 364 份令牌中，内嵌签名证书的为 FreeTSA 83 份、DigiCert 18 份，另有 263 份不内嵌签名证书（2026-11-19 实测）。

📜 作用边界：时间戳只证明"某文件在某时刻已存在"，可作为存在性的辅助证据，不证明权利归属，也不构成对代码安全性的背书。

🔗 校验方式：仓库脚本 node scripts/tsr-verify.cjs（解包 TimeStampResp、校验证书链、比对摘要）。

⚠️ 说明：263 份令牌不含签名证书，只能说明请求已提交，无法仅凭令牌判定签发机构；对外不将它们归入任何 TSA。

⚠️ 重要提示

1. .tsa 文件是 PKCS#7/CMS 封装的时间戳令牌，含 TSA 签名，需使用验证工具解析。

2. 本地校验：node scripts/tsr-verify.cjs --root . --dir <目录>。

3. 时间戳仅证明"某文件在某时刻已存在"，不证明代码质量或安全性。

4. 上述 .tsa 存证文件当前不公开提供；如需查阅（核验、司法/合规用途），可通过项目官方邮箱申请。

🔍 如何验证时间戳？

方法1：仓库校验脚本（推荐）

脚本会解包 TimeStampResp、取出 TimeStampToken、校验证书链并比对被签名覆盖的摘要，输出每个令牌的判定类别。

方法2：使用 OpenSSL（命令行）

openssl ts -reply -in 文件名.tsa -text

输出将显示：

  • 时间戳签发机构: FreeTSA 或 DigiCert（取自令牌内嵌签名证书；不含证书的令牌无法判定）
  • 时间戳创建时间: 2026-05-23 12:34:56 CST
  • 消息摘要算法: SHA-256
  • 签名算法: 随签发机构而定（FreeTSA 与 DigiCert 均为 RSA + SHA-256）

方法3：DigiCert 辅助存证

部分开发日志文件通过 DigiCert TSA 存证，可使用 RFC 3161 标准工具验证。
