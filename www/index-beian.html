安全通信协议

后量子安全

采用 NIST 标准化的 ML-KEM-768 密钥封装机制，抵御量子计算机的 Shor 算法攻击，确保长期数据安全。

端到端加密

Double Ratchet 算法确保每条消息都有独立的加密密钥，即使长期密钥泄露，历史消息依然安全。

零知识认证

基于 zk-SNARKs 的零知识证明认证系统，无需暴露身份信息即可完成身份验证。

高性能 WASM

核心加密算法使用 Rust 编译为 WebAssembly，在浏览器中实现接近原生的执行性能。

跨平台支持

支持 Web、Android、iOS 和桌面端，统一的安全协议确保跨设备通信的一致性。

透明可审计

核心协议接受独立安全审计，透明可验证，代码即信任。

01

传输层安全

ML-KEM-768 X25519 TLS 1.3

使用 NIST 后量子密码学标准 ML-KEM-768 与 X25519 椭圆曲线进行混合密钥交换，建立抗量子计算攻击的安全通道。

02

消息层加密

Double Ratchet AES-256-GCM HKDF

Signal Protocol 的 Double Ratchet 算法确保每条消息独立加密，前向安全和后向安全双重保障。
