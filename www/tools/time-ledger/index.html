密码时间账本

Crypto Time Ledger · 可复现 RFC 3161 时间戳链

手卷 · 时间链

横向展开如赵孟頫手卷：每一墨点为一个账本时间点（block），墨线串接即链连续； 若某点 hash_prev 与前一 hash_now 不符，则此处朱红断笔，明示链断。

墨点 = 时间点 青绿 = 链连续 朱红 = 链断

验真 · 浏览器内复算

下方按钮在浏览器用 Web Crypto 重算每 block 的 hash_now（采用与 core.ts 一致的 RFC 8785 风格键排序），并校验链连续性与 TSR 附着标记。 TSR 签名验真在服务端 cli.ts add 已执行（本页仅标注其附着）。

本页为演示种子数据：3 个 block 由 fibemate-tools 的 crypto-time-ledger 工具经 cli.ts add 真实写入，每个 TSR 均由 test/fixtures 中真实 .tsr + pinned-certs.pem 密码学验签通过 （d22f33f6… 因签发证书不在锚点内，系工具故意负例，未纳入）。
git_commit = 0c4f3c3（fibemate-tools 当时 HEAD，可复现）。 非生产测量，不代表任何真实业务时间线。
