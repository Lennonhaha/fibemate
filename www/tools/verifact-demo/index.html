verifact · report viewer

把报告画出来，不替它下结论

这个页面接收 verifact verify --format json 的输出文件，按文件里写的字段原样渲染。 它不知道什么是"安全"，也不会把任何状态改写成别的状态。

契约 本页面仅渲染离线审计报告，不执行任何安全判定。
把 verifact 的 JSON 报告拖到这里，或

怎么生成这份 JSON：npx verifact verify --format json --out report.json（0.2.1 起可直接用 npx）。

"真实运行（抽样）"：来自本仓库的一次真实扫描（343 份文档 / 2262 条声明 / drift 0），表格按状态各抽 6 条，计数仍为全量值。

"合成示例（红色路径）"：人工构造，只为展示 drift 的渲染样式，页面顶部会强制出现 SYNTHETIC 标记。

算术对账：页面自己把报告里的数字加一遍 —— 2,118 + 17 + 1 = 2,136（瓦片合计 + ref-found + ref-missing = counts.claims），再 2,136 + 126 = 2,262（非代码制品 = reference / disposition / denied / ignored）。对不上就整块变红，不会显示成正常。

状态颜色只映射报告里的字符串；未知状态显示为灰色 st-unknown 并原样打印，不会落回绿色。
