Generated by `node scripts/tsa-issuers.cjs --write`. Do not hand-edit: the table is
evidence, and a table a human types is not evidence.

- Measured: 2026-11-19 over 364 tracked token(s)
- Tokens: **364** tracked `.tsr` files, version 3.3.3
- Method: `openssl ts -reply -token_out`, then `openssl pkcs7 -print_certs`; the
  issuer comes from the signer certificate inside the token, never from the file name,
  the directory, or the page that links it.

## Scope

This table covers the tracked .tsr files. It deliberately does not rewrite:

- docs/tsa/** stamped snapshots and archives/**: they are the attested object, and
  editing them would change what the timestamp was taken over;
- NOTICE and www/LICENSE.txt, which name services used over time, not tokens;
- tools/tsa_cn.py, the client that submits to a TSA, not a claim about any token
  that already exists.

A live page may therefore name FreeTSA or DigiCert, or say the token carries no
signer certificate. scripts/check-tsa-claims.cjs enforces that.

signature can still be checked against a TSA certificate fetched separately, but the
file alone does not name the issuer. Do not describe these as "tsa.cn" or as any other
authority without that separate certificate.
