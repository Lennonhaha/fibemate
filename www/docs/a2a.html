A2A Interface v1.0

最后更新：2026-06-09

端点列表

POST /a2a/register

注册 A2A 节点。请求体：{ nodeId:...,publicKey:...}

POST /a2a/message

发送 A2A 消息。认证：Bearer Token

POST /a2a/burn

阅后即焚消息。消息在指定时间后自动销毁

POST /a2a/group

创建或管理 A2A 群组

GET /a2a/health

健康检查端点。返回节点状态和最后活跃时间

认证方式

API Key (Bearer Token)，通过 Authorization: Bearer <token> 请求头传递。

审计日志

JSON Lines 格式写入 /var/log/fibemate/a2a-audit.log，每行一条完整 JSON 记录。
