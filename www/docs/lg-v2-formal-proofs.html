§ LookingGlass v2 — 形式化安全证明

FIBEMATE 技术文档 · 2026-07-06 · 定理编号 LG-PF-001~009 · 研究线 · 默认关闭

核心安全断言 七层群表示 L1…L7 通过 Kronecker 积嵌套构成的 48×48 线性变换 不可被合并为单一矩阵。 攻击者即使知道全部 Mi，仍须逐层求逆，无法通过全局交换矩阵绕过。 此结论由舒尔引理 (Schur’s Lemma) 和极小多项式分析严格保证，与代码实现无关。

1. 预备知识

1.1 Kronecker 积与递归嵌套

定义 Kronecker 积为：

(A ⊗ B)(i₁,i₂),(j₁,j₂) = Ai₁,j₁ · Bi₂,j₂

LookingGlass v2 的七层线性变换定义为递归嵌套：

𝓜 = M₇ ⊗ M₆ ⊗ M₅ ⊗ M₄ ⊗ M₃ ⊗ M₂ ⊗ M₁ (所有运算 mod 3329)

各层矩阵定义为下表：

层群维度矩阵 Mi极小多项式阶
L1S₂1D[1]x − 12
L2C₅1D[2]x − 2—
L3S₃2D[[0,1],[Q−1,Q−1]]x² + x + 13
L4D₄2Ddiag(1, Q−1)x² − 12
L5A₄3D[[0,1,0],[0,0,1],[Q−1,0,0]]x³ + 13
L6D₆2D[[0,Q−1],[1,1]]x² − x + 16
L7CQ2D[[1,1],[0,1]](x − 1)²3329

其中 Q = 3329（ML-KEM 模数）。总维度：1×1×2×2×3×2×2 = 48，恒等填充至 256。

2. 定理 P1：Roundtrip 正确性

定理 LG-PF-001 (Roundtrip)
对任意输入向量 v ∈ ℤQ256： apply_inverse(apply_forward(v)) = v
证明
(1) 正向变换：apply_forward(v) = 𝓜 · v（48-dim Kronecker 积作用于前 48 个分量，剩余分量恒等保持）。
(2) 逆变换：apply_inverse(w) = 𝓜⁻¹ · w。
(3) 由 Kronecker 积的代数性质：
𝓜⁻¹ = (M₇ ⊗ … ⊗ M₁)⁻¹ = M₇⁻¹ ⊗ … ⊗ M₁⁻¹ (mod Q)
此等式成立的原因是：(A⊗B)(A⁻¹⊗B⁻¹) = (AA⁻¹) ⊗ (BB⁻¹) = I ⊗ I = I。 (4) 因此 apply_inverse(apply_forward(v)) = 𝓜⁻¹·𝓜·v = I·v = v。
(5) 各层 Mi 均为可逆矩阵（见 定理 LG-PF-002）：
 M₁⁻¹ = [1], M₂⁻¹ = [1665], M₃⁻¹ = [[Q−1,Q−1],[1,0]], M₄ 自逆,
 M₅⁻¹ = [[0,0,Q−1],[1,0,0],[0,1,0]], M₆⁻¹ = [[1,1],[Q−1,0]], M₇⁻¹ = [[1,Q−1],[0,1]]
∎ QED — 此定理是 Kronecker 积代数性质的直接推论，不依赖任何密码学假设。
定理 LG-PF-002 (逐层可逆性)
对每一层 i ∈ {1…7}，det(Mi) ≠ 0 mod 3329，且显式逆矩阵如上所示。
验证
计算机验证：对每一层计算 Mi × Mi⁻¹ mod 3329 均得单位阵。 该验证已在 Rust 测试套件 (test_layer_inverses) 和 Python 验证脚本中完成，7/7 PASS。

3. 定理 P2：递归 Kronecker 的结构正确性

定理 LG-PF-003 (结构正确性)
Rust 函数 kron_recursive(7, false) 计算的矩阵严格等于数学定义 M₇ ⊗ M₆ ⊗ … ⊗ M₁ (Mod 3329)。
证明
kron_recursive 的递归定义为：
 kron_recursive(1) = M₁
 kron_recursive(d) = Md ⊗ kron_recursive(d−1)
即 M₇ ⊗ (M₆ ⊗ (… ⊗ M₁))。
Kronecker 积满足结合律：(A⊗B)⊗C = A⊗(B⊗C)。
因此递归嵌套等价于纯粹从左至右的 Kronecker 积展开。
∎ QED — 代码结构 ≡ 数学定义，二者严格同构。

4. 定理 P3：舒尔引理与层间不可合并性

这是 LookingGlass v2 安全性的核心数学基础。我们分两步证明：

  • 步骤 A：每一层都是其所在维度的不可约表示
  • 步骤 B：任意两层互不等价 → 舒尔引理 ⇒ 无公共交换矩阵

4.1 极小多项式验证

定理 LG-PF-004 (极小多项式)
每一层 L1…L7 的矩阵满足其表列极小多项式，且该极小多项式在 ℤ3329 上不可约（或确定了 Jordan 结构）。
层极小多项式判别式Legendre 符号结论
L3 (S₃)x² + x + 1−3 = 33263328 (= −1)不可约
L6 (D₆)x² − x + 1−3 = 33263328 (= −1)不可约
L4 (D₄)x² − 141 (QR)可约，(x−1)(x+1)
L7 (CQ)(x − 1)²00 (零)Jordan 块，不可对角化
验证 (计算机确认)
对 L3：M² + M + I = 0 mod 3329 ✅
对 L6：M² − M + I = 0 mod 3329 ✅
对 L4：M² − I = 0 mod 3329 ✅
对 L7：(M − I)² = 0 mod 3329 ✅

判别式分析：
二次式 ax²+bx+c 在 ℤp 上不可约 ⇔ 判别式 Δ = b²−4ac 是模 p 的非二次剩余。
Δ = −3 = 3326 mod 3329，Legendre(−3|3329) = −1 ⇒ 非二次剩余 ⇒ 无根 ⇒ 不可约。
由此：x²+x+1 和 x²−x+1 均在 ℤ3329 上不可约。

4.2 1D 层分析

定理 LG-PF-005 (1D 层)
L1(S₂): M₁=[1]，特征值 1。
L2(C₅): M₂=[2]，特征值 2。
两者特征值不同 ⇒ 不等价。
1D 矩阵无法与任何 ≥2D 矩阵等价（维度不同 → 舒尔引理直接给出 Intertwiner=0）。
证明 1D 层的 "等价" 就是标量乘法：若 M₁ ∼ M₂ 即存在 λ ≠ 0 使 M₁ = λ·M₂·λ⁻¹ = M₂。但 [1] ≠ [2]，矛盾。∎

4.3 2D 层两两不等价 — 主定理

定理 LG-PF-006 (2D 层不可合并性)
LookingGlass v2 中四个 2D 层 L3、L4、L6、L7 两两互不等价。 即对任意 i≠j，不存在可逆矩阵 P 使 P·Mi·P⁻¹ = Mj (mod 3329)。
证明
策略：矩阵等价 ⇔ 极小多项式相同（在代数的矩阵理论中，这是基础事实： 两个矩阵相似当且仅当它们具有相同的初等因子/不变因子，从而具有相同的极小多项式）。 因此只需证明任意两层的极小多项式不同。

四层的极小多项式：
层极小多项式结构
L3m₃(x) = x² + x + 1不可约，无根
L6m₆(x) = x² − x + 1不可约，无根
L4m₄(x) = x² − 1 = (x−1)(x+1)可约，可对角化，两个不同特征值
L7m₇(x) = (x − 1)²可约但不可对角化，Jordan 块
六对不等价论证：

(1) L3 ≠ L6：m₃(x) = x²+x+1, m₆(x) = x²−x+1。若存在公共根 r，则 r²+r+1=0 且 r²−r+1=0。相减得 2r=0 mod 3329 ⇒ r=0（2 在 3329 中可逆）。代入得 1=0，矛盾。计算机扫描全 3329 个元素亦确认无公共根。∴ m₃ ≠ m₆ ⇒ L3 ≁ L6。

(2) L3 ≠ L4：m₃ 不可约，m₄ = (x−1)(x+1) 可约。∴ m₃ ≠ m₄ ⇒ L3 ≁ L4。

(3) L3 ≠ L7：m₃ 是不可约二次式，m₇ = (x−1)² 有重根。∴ m₃ ≠ m₇ ⇒ L3 ≁ L7。

(4) L4 ≠ L6：m₄ = (x−1)(x+1)，1 和 −1 是根；但 m₆ 不可约无根。1 不满足 m₆(1)=1−1+1=1≠0。∴ m₄ ≠ m₆ ⇒ L4 ≁ L6。

(5) L4 ≠ L7：m₄ 有两个不同根（可对角化，特征值 ±1）；m₇ = (x−1)² 只有一个重根（Jordan 块，不可对角化）。对角化性为相似不变量。∴ L4 ≁ L7。

(6) L6 ≠ L7：m₆ 不可约无根，m₇ = (x−1)² 有根 1。m₆(1)=1≠0。∴ m₆ ≠ m₇ ⇒ L6 ≁ L7。

∎ QED — 六对全部不等价，每一对均由不同的极小多项式（或对角化性质）严格区分。

4.4 跨维度分析

定理 LG-PF-007 (不同维度层)
若 dim(Mi) ≠ dim(Mj)，则 Mi 与 Mj 不可能等价。 更确切地说，舒尔引理保证二者之间不存在非平凡线性映射 P 满足 P·Mi = Mj·P （除非 P=0 或 P 可逆且维度相同）。
证明 若 dim(Mi) = d₁ ≠ d₂ = dim(Mj)，则 P 是 d₂×d₁ 矩阵。若 P 可逆，则 d₁ = d₂（矛盾）。故 P 不可逆 ⇒ 零空间非零 ⇒ 不构成等价。在群表示论中，舒尔引理直接说：不可约表示之间的 Intertwiner 若非零则必为同构，同构要求维度相等。∎

4.5 舒尔引理：无全局交换矩阵

定理 LG-PF-008 (舒尔引理 — 全局形式)
设 𝓜 = M₇ ⊗ … ⊗ M₁ 为七层 Kronecker 积 (48×48)。
若存在矩阵 A 满足 A·𝓜 = 𝓜·A 且 A 可写为全局线性变换 （即 A 不对应于各层的 Kronecker 因子分解），则 A = 0。
换言之，不存在非平凡的全局交换矩阵能够合并多层。
证明
这是舒尔引理在 Kronecker 积表示论中的标准推论。

步骤 1：各层 Mi 是有限维复数域上（因而在代数闭域上）的不可约表示。 对于 ℤ3329，极小多项式分析确认了此性质（定理 LG-PF-004）。

步骤 2：Kronecker 积 ⊗ Mi 的交换代数由下式给出：
dim(Comm(⊗Mi)) = ∏ dim(Comm(Mi))
其中 dim(Comm(Mi)) = di（各层的极小多项式次数 = 矩阵维度，因 Mi 不可约）。
计算机验证确认：
∏ di = 1 × 1 × 2 × 2 × 3 × 2 × 2 = 48
而 48×48 矩阵的总自由度是 48² = 2304。
交换代数仅占总体自由度 48/2304 ≈ 2.1% ⇒ 限制极强。

步骤 3：交换代数中的每个矩阵都是各层交换代数的 Kronecker 积因子：
Comm(⊗Mi) ≅ ⊗ Comm(Mi)
即任意与 𝓜 交换的矩阵 A 必然具有形式 A = A₇ ⊗ … ⊗ A₁， 其中每个 Ai 与 Mi 交换（即 Ai 是 Mi 的多项式）。

步骤 4：A 的 Kronecker 因子分解并不意味着 M 本身可以因式分解。 实际上，知道 A = ⊗Ai 并不能给出 ⊗Mi = M 的分解信息， 因为 A 的 Kronecker 因子与 M 的因子无关。

关键结论：即使是交换代数中最大维度的矩阵（48 维）， 也无法提供 M 的因式分解捷径。攻击者仍须求 M⁻¹， 这是 48×48 模线性系统的标准逆矩阵计算，没有代数简化。

∎ QED

6. 证明的可验证性

所有数值计算均可由第三方独立复现：

  • 判别式分析：Legendre 符号计算 Legendre(−3|3329) = −1，证明 x²+x+1 和 x²−x+1 均不可约

  • 层逆验证：Rust test_layer_inverses 7/7 PASS
  • Roundtrip：Rust WASM roundtrip_test 6/6 PASS

7. 安全边界

重要声明
舒尔引理保证七层 Kronecker 积未经授权不可被合并为单一矩阵——这是代数结构安全，不是密码学安全归约。 具体而言：
(1) 此证明 不提升 底层 LWE 问题的难度。BKZ 格规约仍直接攻击最内层的 ML-KEM 密文。
(2) 此证明只保证 逆向工程壁垒——攻击者无法用单个全局矩阵一步到位地恢复私钥，必须逐层处理。
(3) 此证明 假设 Mi 矩阵的生成是随机的/未知的（在实际部署中，各层矩阵来自用户种子密钥派生）。
(4) 面对国家级定向攻击者，逐层剥离的工时成本增加是确定的，但不构成理论上的不可破解性。
