# 欢迎来到 FIBEMATE 社区！

## 关于 FIBEMATE

FIBEMATE 是一个全栈后量子密码学工程验证平台，聚焦三条技术线：

- **标准 PQC**: ML-KEM-768 + SLH-DSA（生产就绪）
- **国密混合**: SM2/SM3/SM4 + ML-KEM（IANA #4590）
- **前沿研究**: LookingGlass、VWZ 签名、FPGA 硬件加速
