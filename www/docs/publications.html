Engineering Hardening and High-Order TVLA Evaluation for SM2 Elliptic Curve Implementation

掩码失效诊断 N=2000 假阴性 三重防护 1-4 阶 20/20 全绿 3.8× 代价量化
Abstract
Timing side-channel leakage remains a major threat to elliptic curve cryptography implementations. In this work, we report a complete bug-hunting and hardening story for a pure JavaScript SM2 implementation based on native BigInt. A well-known but frequently misimplemented scalar masking scheme failed completely due to an unnecessary modulo reduction, which remained invisible under small-scale TVLA with N=2000 and only emerged after we raised the sample size to N=5000. We then build a three-layer countermeasure suite: scalar blinding without modulo truncation, projective coordinate randomization, and Montgomery ladder constant-time scalar multiplication. Beyond first-order Welch's t-test, we carry out high-order TVLA covering mean, variance, skewness and kurtosis (1–4 statistical moments). All 20 test cases pass with maximum |t| < 1.24, far below the threshold 4.5.
Keywords: SM2; side-channel analysis; TVLA; high-order t-test; scalar masking; Montgomery ladder; timing leakage

A 5-Stage Pipelined NTT with B=32 Barrett Reduction: Theory-vs-Measurement Decomposition and Path to 11.8× Acceleration

流水线≠吞吐量 6.5× 差距拆解 双 FIFO 投影 256/256 全匹配 11.8× 路线图
Abstract
This paper presents a latency-decomposition analysis of a 5-stage pipelined number-theoretic transform (NTT) implementation for ML-KEM-768 on a Xilinx Artix-7 FPGA. The design achieves 2-DSP48E1 utilization through a unified Cooley–Tukey/Gentleman–Sande butterfly with B=32 Barrett modular reduction. While classic utilization-based models predict 1029 cycles (99.5% pipeline efficiency), RTL simulation with a 7-deep address pipeline and 2-deep write-back queue measures 6652 cycles — a 6.5× gap. We decompose this gap into per-stage feed–drain overhead (6265 cycles across 127 groups) and FSM overhead (387 cycles), and project that dual-FIFO group overlap reduces latency to 1065 cycles (11.8× over serial, 6.25× over current pipelined implementation).
Keywords: NTT; Barrett reduction; ML-KEM; FPGA; pipeline decomposition; latency analysis
